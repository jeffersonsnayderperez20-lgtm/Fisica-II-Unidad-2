# CampoLab - Física II - Unidad 2

Autor: Jefferson Snayder Perez Culqui.

Presento mi simulador de capacitores y dieléctricos. Puedo variar el área, la separación, la permitividad y el voltaje, y comparar un capacitor conectado con uno desconectado.

## Archivos

- **index.html**: aplicación compilada con sus recursos incluidos, preparada para el navegador.
- **codigo-fuente.zip**: fuentes originales editables en React y TypeScript, cinco pruebas e instrucciones para ejecutar y compilar.

En el motor calculo C = ε₀ εᵣ A/d, Q = CV, U = CV²/2 y E = V/d en SI. Al desconectar conservo Q y recalculo V. Uso un modelo ideal sin efectos de borde, pérdidas, ruptura ni transitorios. Las dimensiones de dibujo tienen escalas visuales distintas de las físicas.
